# Breast Cancer Classification Using Python

## Project Overview

This project uses Python and machine learning techniques to classify breast tumors as benign or malignant using the Breast Cancer Wisconsin dataset. The goal is to explore medical data, identify patterns, and evaluate the performance of different classification algorithms.

The project demonstrates practical skills in data preprocessing, exploratory data analysis, machine learning, and model evaluation.

## Technologies Used

- **Python** – Data analysis and machine learning
- **Pandas & NumPy** – Data manipulation and preprocessing
- **Matplotlib** – Data visualization
- **Scikit-learn** – Machine learning model development and evaluation
- **Jupyter Notebook** – Development and documentation

## Project Workflow

1. **Data Exploration:** Examined the dataset to understand its structure, features, and target classifications.
2. **Data Preprocessing:** Prepared the dataset for analysis, including feature scaling and training/testing splits.
3. **Exploratory Data Analysis:** Used statistical summaries and visualizations to investigate patterns in the data.
4. **Model Development:** Implemented K-Nearest Neighbors (KNN) and Logistic Regression classification models.
5. **Model Evaluation:** Compared model performance using accuracy, confusion matrices, precision, recall, and F1-scores.

## Results

| Machine Learning Model | Accuracy |
|---|---|
| K-Nearest Neighbors (KNN) | 95.6% |
| Logistic Regression | 96.5% |

Logistic Regression achieved the highest accuracy, demonstrating strong performance in distinguishing benign from malignant tumors.

These results highlight how machine learning can be applied to medical datasets to identify meaningful patterns and support predictive analysis.

1. Clone or download this repository.
2. Open `DAT402_Project2.ipynb` in Jupyter Notebook or JupyterLab.
3. Install the required Python libraries: Pandas, NumPy, Matplotlib, and Scikit-learn.
4. Ensure the dataset is located in the same directory as the notebook.
5. Run the notebook cells in order to reproduce the analysis and results.
